# Nextbuild

Language support for .nextbuild and .nextbuild-dependency in VS Code and Cursor.
The extension adds syntax highlighting, diagnostics, completions, hover,
go-to-definition, document symbols, and build and clean commands.

Install the Nextbuild binary for your platform and add it to PATH, or set
nextbuild.executablePath to its absolute path. Open a trusted workspace and
a Nextbuild manifest to start the language server.

- **Nextbuild: Build** builds the current project or active workspace folder.
- **Nextbuild: Clean** removes build output for that same target.
- **Nextbuild: Restart Language Server** reloads the language server.

Install a release VSIX via **Extensions: Install from VSIX** in either editor.
